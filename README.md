# MyLibrarySystem

MyLibrarySystem 是一个面向单一图书馆的工程学习项目。
项目以完整系统为验收对象，按照 V 模型依次开展需求分析、总体设计、详细设计和模块设计，并分别对应验收测试、系统测试、集成测试和单元测试。

- [后端项目与开发说明](library-server/README.md)
- [前端项目与开发说明](library-frontend/README.md)

### 参与需求评审

1. 从[系统需求主规格](docs/01-requirements/MLS-DOC-RA-0003.md)进入当前需求工件。
2. 在[Open 问题登记册](docs/01-requirements/requirements/MLS-DOC-RA-0007.md)逐项确认尚未决定的业务与质量边界。

4. 只有[需求基线记录](docs/01-requirements/reviews/MLS-DOC-REV-0002.md)完成正式批准后，需求工件才可成为下一阶段输入；变更按[变更控制](docs/00-governance/MLS-DOC-GOV-0004.md)处理。
