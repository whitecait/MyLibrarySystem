## Current Actual State

CodeGraph verified on 2026-07-04.

### Backend

- Current external base path: `http://localhost:8080/api`.
- Current implemented API groups: `/api/auth/*`, `/api/books/*`, `/api/categories/*`, `/api/borrows/*`, `/api/returns/*`, `/api/renewals/*`, `/api/penalties/*`.
- Current backend modules: 8 JPA entities, 8 repositories, 7 controllers, 7 service interfaces, 7 service implementations, and 16 DTO classes.
- P1-P4 backend scope is implemented/current.
- P5 groups are not implemented in the current `com.library` backend: `/api/news/*`, `/api/messages/*`, `/api/upload/*`, `/api/dashboard/*`.
- Current password contract: request password is sent as-is to the backend, then stored/verified with backend BCrypt. Frontend SHA256 pre-hashing is only a possible future enhancement.
- Backend test source currently contains 22 `@Test` methods. The last recorded Surefire result passed with `Tests run: 22, Failures: 0, Errors: 0, Skipped: 0`; fresh rerun requires `JAVA_HOME`.

### Frontend

- Vite proxy now forwards `/api` to `http://localhost:8080`; the old backend context-path rewrite is no longer used.
- Axios defaults to `/api` and sends `Authorization: Bearer <token>`.
- Auth API wrappers are partially migrated to `/auth/login` and `/auth/register`.
- `LoginView.vue` still consumes the auth response as the old shape (`res.token` / `res.user`) instead of `res.data.token` and related fields.
- Most business API modules and views still use legacy pinyin paths/fields.
- `MyFines.vue` still uses the old penalty update flow instead of `POST /penalties/pay`.
- Frontend build has not been verified because dependencies are not installed in this workspace.

## Quick Start

### Backend

```powershell
cd library-server
.\mvnw.cmd spring-boot:run
```

Useful local URLs:

- Swagger UI: `http://localhost:8080/api/swagger-ui.html`
- H2 console: `http://localhost:8080/api/h2-console`

Production profile:

```powershell
cd library-server
.\mvnw.cmd spring-boot:run -Dspring-boot.run.profiles=prod
```

### Frontend

```powershell
cd library-frontend
npm install
npm run dev
```

Frontend dev URL: `http://localhost:5173`.
