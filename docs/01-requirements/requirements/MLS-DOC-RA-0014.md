本矩阵以“一行表示一个明确的需求到验收关系”为原则。`MLS-FR-0011` 来源于两个用例，因此保留两行关系；功能需求唯一项为 47 项（含 ODV 传导 FR-0047）（`MLS-FR-0029`~`0035` 为 AI 需求传导新增，`MLS-DEC-0010`/`0011`/`0012`；`MLS-FR-0036`~`0038` 为三线状态机传导新增，`MLS-DEC-0018`；`MLS-FR-0039` 为到馆统计口径传导新增，`MLS-DEC-0019`；`MLS-FR-0040`~`0046` 为读者页业务口径传导新增，`MLS-DEC-0016`）。业务规则、信息需求和已形成验收关系的非功能需求各选择一个直接验收关系作为主追踪入口，其他实际覆盖关系保留在验收用例正文中；验收条件定义于来源条目且指标已量化的 NFR（`MLS-OQ-0010` 至 `MLS-OQ-0015` 已关闭）在验收条件列标记为「定义于来源条目（MLS-NFR-xxx）」，不再使用 `Not assigned`；AI 相关行（`MLS-FR-0029`~`0035`、`MLS-BR-0026`~`0031`、`MLS-IR-0013`~`0015`、`MLS-NFR-AI-0001`~`0006`、`MLS-AT-0019`/`0020`）的关闭依据为 `MLS-DEC-0012`（`MLS-OQ-0016`~`0020` 已于 2026-09-06 关闭），其中呈现形态、额度计数与日志粒度相关行的现行口径另依 `MLS-DEC-0021`（2026-09-09，`MLS-OQ-0021`/`0023`/`0024` 关闭传导修订条目值，追踪关系行不变）；三线状态机相关行（`MLS-FR-0036`~`0038`、`MLS-BR-0032`~`0035`、`MLS-IR-0016`、`MLS-AT-0021`~`0023`）的批准依据为 `MLS-DEC-0018`（2026-09-08）；首页到馆统计相关行（`MLS-FR-0039`、`MLS-BR-0036`、`MLS-IR-0017`、`MLS-AT-0024`）的批准依据为 `MLS-DEC-0015`/`MLS-DEC-0019`（2026-09-08）；读者门户相关行（`MLS-FR-0040`~`0046`、`MLS-BR-0037`/`0038`）的批准依据为 `MLS-DEC-0016`（2026-09-07），其中 `MLS-FR-0044` 的排序口径另依 `MLS-DEC-0020`（2026-09-08）；AI 相关 NFR 的验收条件定义于来源条目（`MLS-DOC-RA-0013` §10），以「定义于来源条目」标记。后续列按已存在的设计/测试规格回填；文档 ID 表示规格入口，不表示测试代码存在或运行通过。Not created 表示该条目尚无具体下游工件。质量签署候选相关行（`MLS-NFR-PER-0002`~`0004`、`MLS-NFR-REL-0002`、`MLS-BR-0039`~`0045`、`MLS-AC-0047`~`0049`、`MLS-AT-0029`/`0030`）的批准依据为 `MLS-DEC-0023`（2026-09-10，B1-C C2 质量签署候选确认），其中 `MLS-NFR-PER-0002` 的验收条件定义于来源条目，其余三项分别显式连接 `MLS-AC-0047`、`0048`、`0049`。

- 正向检查：每个已形成可执行边界的需求至少能到达一个明确验收关系；范围约束明确标记为 `Not applicable`，不得伪造验收关系。
