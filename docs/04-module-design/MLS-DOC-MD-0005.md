## 2026-10-01 当前适用范围与批准修订

lingzz 于 2026-10-01 明确批准 A–E，并追加新增功能 TLA 形式化回归、CI 验证及完整 PR 流程要求。本节与[限定范围交付与 DevOps 阶段规则](../00-governance/MLS-DOC-GOV-0008.md)共同限定当前适用内容；下文相冲突的范围、角色、状态和准入表述保留为原基线历史，其余约束继续有效。批准修订与执行验证分别登记。

P3/P4 的浏览器豁免、单轮性能和局部影响复用仅说明那些批次的获批证据边界；支付/审计样本不足、未作 P99/三轮/长期稳定性声明继续保留。新阶段按变更影响复验；新增功能必须有对应 TLA+ 模型或明确抽象映射并执行形式化回归，通过当前 PR 提交的 CI，完成评审、整改及合并流程。模型结论与真实 PostgreSQL/HTTP 结论分别提供。

模块主责、合同生成物一致性、架构检查、真实数据库集成与运行恢复继续保留。旧全量 FR 主责表及 UT/IT 目录不是当前逐项执行证据；退款/对账成功用例退出，拒绝及旧审批零写效果属于现行责任。现有 CI 尚无 TLA 作业，CI 接合与模型版本化是当前待办；新增功能在这两项完成前不能按新规则发布。

### 3.1 契约与依赖门禁

| ID | 自动检查 | 失败条件 |
| -- | -------- | -------- |
| `CONTRACT-001` | OpenAPI 3.1 解析、内部 `$ref` 完整性、45 个 `operationId` 唯一 | 文件不可解析、引用缺失、操作缺失或重复 |
| `CONTRACT-002` | 前端生成类型/客户端与 OpenAPI 当前哈希一致；页面不手写 URL | 生成物漂移或模块绕过 `platform/http` |
| `CONTRACT-003` | 后端 Controller 请求/响应及 14 个共同场景逐操作通过 OpenAPI 校验 | 字段、必填性、枚举、空值、状态码、所有权安全方案或幂等头不一致 |
| `ARCH-BE-001` | `ModuleDependencyRulesTest` | 跨模块导入 `internal`/持久化 Adapter，或应用用例导入聚合模块接口 |
| `ARCH-FE-001` | `npm run architecture:check` | 跨模块导入其他模块 `internal`，或在 `platform/http` 外直接发起 HTTP |

`CONTRACT-002` 的生成命令及生成器版本已经固定；生成物必须可由 OpenAPI 单命令重建，不接受手工维护副本。匿名 AI OpenAPI 2.0 候选按用户选择不在本轮重建前端生成物，因此 operations、TypeScript 类型和前端共同样例副本的哈希漂移是已知、预期且阻塞合并的失败，不能宣称全量门禁通过；恢复门禁属于后续实现任务。`CONTRACT-001` 的 OpenAPI 解析通过；`CONTRACT-003` 的源样例 Schema、逐操作请求与响应结构通过，但现有实现测试仍硬编码 9 个样例且稳定码枚举未登记 `MLS-AI-005`，完整门禁保持失败并随 AI 实现修复。`ARCH-BE-001/ARCH-FE-001` 已在工程骨架建立，并随现有测试/检查命令执行。

## 4. 集成场景目录

| ID | 场景与三层断言 |
| -- | -------------- |
| `IT-ID-001` | 并发自助注册：一个成功、一个稳定冲突；库内一账户一角色；审计关联唯一 |
| `IT-ID-002` | 角色与对象权限：HTTP 401/403/404 正确；不可见数据不泄漏；拒绝审计存在 |
| `IT-CAT-001` | 固定检索标注集执行 pg_trgm；结果、数据库计划与 SLI 证据可关联 |
| `IT-CAT-002` | 书目版本竞争和软删除约束；冲突不覆盖新值 |
| `IT-CIRC-001` | 同副本借阅竞争；一成功一冲突，副本单占用、Outbox 唯一 |
| `IT-CIRC-002` | 候补队首、失格跳过和确认重验；FIFO 与审计理由一致 |
| `IT-CIRC-003` | 归还形成罚款；流通、罚款、Outbox 同事务，故障整体回滚 |

| `IT-CIRC-006` | 自助混合批次；逐册独立提交与结果，不因一册失败回滚其他册 |
| `IT-PAY-001` | 同罚款并发建单；部分唯一索引保证至多一个未释放订单 |
| `IT-PAY-002` | 回调重复、乱序、冲突；首次效果唯一，冲突只留证 |
| `IT-PAY-003` | 关闭提交失败、超时和终态迟到；占用与终态不被误改 |
| `IT-PAY-004` | 全额/部分退款授权、金额守卫和审计 |
| `IT-PAY-005` | 固定业务日日终对账；重复运行幂等，异常可追踪 |
| `IT-REV-001` | 批准决定、目标动作、Outbox 整体提交；任一步失败整体回滚 |
| `IT-REV-002` | 目标版本已变返回 `MLS-REV-001`；目标不变并允许重新发起 |
| `IT-QUERY-001` | 门户、我的业务和到馆统计按角色组合，缓存陈旧不改变提交结果 |
| `IT-AI-001` | 每次工具调用重新授权，越权参数不进入查询或业务模块 |
| `IT-AI-002` | L2/L3 卡片只形成会话事件；取消无业务请求，提交走现行契约 |
| `IT-AI-003` | 模型成功/失败/超时/重试的额度和轮数；事件逐条留存 |
| `IT-AI-004` | `thinking=disabled` 生产 profile 契约测试；provider-default 保留为不兼容回归场景 |
| `IT-AI-005` | 匿名启动设置安全 Cookie，原值不进正文/库/日志；正确 Cookie 可连续访问，缺失凭据 401、错误凭据不可见 404／`MLS-AI-005` |
| `IT-AI-006` | 访客会话同时收到 Bearer 仍保持 VISITOR 与访客额度；Bearer 新建会话归账户；所有者类型不迁移 |
| `IT-AI-007` | 两个访客并发消耗同一业务日全局额度，CAS 不超扣；账户额度不受影响 |
| `IT-AI-008` | 追加迁移保留既有账户会话，强制账户/访客所有者 XOR，重复迁移无变化，V1 校验和不漂移 |
| `IT-DEL-001` | Outbox 崩溃后至少一次重投；同消费者同事件效果唯一 |
| `IT-DEL-002` | 不同消费者和不同事件互不吞并；回执与消费效果同事务 |
| `IT-DEL-003` | 同一预约事务 VISIT/NO_VISIT 互斥，不同事务可同日并存并正确排序 |

所有高风险集成场景同时断言接口结果、数据库不变量和日志/指标/事件证据。DD-0006 既有 `C/P/X/R` 场景继续有效，本目录补齐身份、书目、退款、对账、查询、AI 和通知责任。

## 5. 环境与推迟边界

- 单元测试、静态契约检查、前后端构建以及不需要真实页面操作的集成测试可在 WSL 执行。
- Playwright 真实页面、8 张 Mermaid 新渲染视觉检查和 Grafana 实页取证必须移交 Windows 原生环境。本轮只登记 `E2E-001`、`E2E-AI-001` 的责任与前置数据，不把未执行浏览器操作记为通过。
- Docker 不可用时，Testcontainers 场景不得用 H2 或内存数据库替代；保留已有 19 项成功证据，但源码变化后应在 Docker 可用环境重跑受影响测试。
- AI 生产配置使用 `thinking=disabled`（`MLS-DEC-0030`）；端点兼容测试不替代完整 AI 权限、额度、工具循环与业务验收。
